# Paxence — MUN Committee Guide

A responsive, single-page Model United Nations handbook. It covers committee flow, debate terms, motion wording, speech structure, diplomatic phrasing, resolution drafting, and delegate strategy. It is built with plain HTML, CSS, and JavaScript, so GitHub Pages can publish it without a build step.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Add `index.html` to the root of your repository (or publish this folder as the site root).
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose your branch and `/ (root)`, then save.

The site uses remotely hosted Unsplash photographs and Google Fonts. The speech outline is generated in the browser and is not sent to a server. Motion wording and procedure vary by conference; follow your chair's rules of procedure.
